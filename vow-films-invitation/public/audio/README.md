# Music

Put the website's background track here as **`invitation-theme.mp3`**
(the path is set in `wedding.config.ts → music.src`).

- Use only music you own or have licensed for this commercial use.
- No music file is included. Until you add one, the music button hides itself automatically and everything else works.
- Music never starts by itself — only after the visitor clicks **ENTER INVITATION**.
- Tip: 128 kbps MP3, 60–120 s, a seamless loop, under 3 MB.

For the film, set `film.audioSrc` in `wedding.config.ts` (for example `"/audio/film-theme.mp3"`).
